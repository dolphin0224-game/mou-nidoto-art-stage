# もう二度と — 夜の宿・立体モデル比較版 v7

v7：スキンメッシュの靴底を実測して石畳の上面へ接地。腰の上下動を除去し、靴ごとの柔らかい接地影を追加。

Unity 6000.3.23f1 / WebGL。元ゲームから独立した一場面のアート試作。

## 今回の変更

- 2D人物の切り抜きを、VRoidの既存制服モデル2体へ置換。暖色／寒色の髪色違い。
- 呼吸、体の揺れ、首・腕の微動、瞬きの待機モーション。
- 中庭の石畳、柱、階段、縁側、障子の格子、屋根、柵、花を実際の厚みのあるメッシュで構築。
- 石・木・瓦・紙をまとめた素材アトラスを各部材に割り当てる。元の一枚絵を近景全体に投影する方式は使用しない。遠景だけは背景画像。
- マテリアルごとに静的メッシュを結合し、部材数がそのまま描画回数にならないよう整理。

## 操作

WASD / 矢印キーで移動。右ドラッグ / Q・Fで見回す。Rで開始位置。画風ボタンでドット／月夜／鉛筆／厚塗りを比較。動きON/OFFで待機モーションと浮遊物を停止・再開。

移動範囲は中庭内。宿の中には入れない。視線は左右360度回せる。キャラクターは固定位置で待機し、プレイヤーを追従して歩かない。

## 利用したモデルと範囲

pixiv / VRoid Project「β Ver AvatarSample_1」（旧AvatarSample_D）を使用。栞・陽菜の完成モデルではなく、無料既存モデルによる質感・立体感の比較用。衣装や顔の造形は配布モデル由来。髪色とUnity用材質のみ調整。詳細な出典・利用条件は [THIRD_PARTY.md](THIRD_PARTY.md)。

モーションはこの試作向けの手続き的な待機動作。歩行、ゲームプレイ用の状態遷移、髪の衝突を含む本格的な揺れ物は未実装。

## 再ビルド

同梱のUnityプロジェクトを開き、Art Stage > Rebuild Scene。バッチ実行は -executeMethod ArtStageBuild.Build -buildTarget WebGL。
Assets/Scripts/ModularInn.cs が部材構築、AvatarIdle.cs が待機動作、Editor/AvatarFactory.cs がモデルの変換後設定を担当。Web実行時はUnityネイティブ形式のメッシュを使う。FBXは制作時の中間形式。
