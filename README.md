# もう二度と — 白薔薇の小庭園 v8

Unity 6000.3.23f1 / WebGL。人物1人、柱、白薔薇、石畳に範囲を絞った画風・情報密度の試作。

## 今回の構成
- 木目・紙の皺・経年変化まで描いた宿の正投影画像を、実際の柱・軒・縁側の奥へ配置。
- 白薔薇・葉・枝・シダの透過画像を曲面へ貼り、複数の奥行き・角度に重ねる。
- 専用石畳テクスチャ、視点で変化する近似的な濡れ反射、夜光と宿の暖色を統一した材質。
- 旧VRoid CC0モデル1体を使用。形状は既存モデルで、材質のみ環境に合わせて調整。呼吸・瞬き・足裏の接地補正と簡易接地影を維持。

WASD / 矢印キーで移動、右ドラッグ / Q・Fで見回し、Rで戻る。小道の移動範囲はX=-1.35〜1.25、Z=-1〜5.3。人物の周囲を回れる。03〜05と厚塗りで画風を比較。動きON/OFFで待機動作と植物の微動を切り替える。

## 範囲と限界
花は完全な立体モデルではなく、細部を描いた曲面カードの集合。接近や真横の角度では面の構造が分かる。宿内部は作っていない。壁の多視点復元、物理的な反射、髪の物理挙動は含まない。人物は栞・陽菜の正式モデルではない。

モデル出典は[THIRD_PARTY.md](THIRD_PARTY.md)。素材と生成プロンプトは[V8_GARDEN.md](V8_GARDEN.md)。

## Unityでの再構築
Art Stage > Rebuild Scene。Webビルドは -executeMethod ArtStageBuild.Build -buildTarget WebGL。
HeroGarden.cs が部材・植物の配置、HeroSurface.shader が夜の材質、AvatarIdle.cs が待機動作・足裏補正を担当する。
